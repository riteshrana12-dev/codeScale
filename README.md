```bash
# Terminal 1 — Backend
cd backend && npm install && cp config/.env.example config/.env
# → fill in config/.env, then:
npm run dev    # http://localhost:3000

# Terminal 2 — Frontend
cd frontend && npm install && npm run dev    # http://localhost:5173
```

**`config/.env` (never commit this):**

```env
DB_URI=mongodb+srv://<user>:<pass>@<cluster>/<db>
JWT_SECRET_USER=your_random_secret_min32chars
JWT_SECRET_ADMIN=your_admin_secret_min32chars
ADMIN_EMAIL=admin@yourdomain.com
ADMIN_CODE=your_admin_code
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
FRONTEND_URL=http://localhost:5173
```

## ✦ Project Structure

```
CodeScale/
├── backend/
│   ├── config/            → DB connect + .env template
│   ├── controllers/       → auth · problems · submission
│   │                        chatbot · analytics · admin
│   ├── middleware/         → JWT guard · admin guard
│   ├── models/            → User · Problem · Submission
│   ├── routes/            → Express route definitions
│   ├── services/
│   │   └── executionEngine.js  ← ✨ sandboxed code runner
│   ├── utils/             → code templates · stats helpers
│   └── server.js          → Express entry point
│
└── frontend/src/
    ├── pages/             → Home · Problems · Editor
    │                        Dashboard · Auth · History
    ├── components/
    │   ├── codeEditor/    → Monaco + Run + Submit + DryRun
    │   ├── chatbot/       → AI assistant widget
    │   └── charts/        → heatmap · leaderboard · stats
    ├── hooks/             → custom React hooks
    ├── services/          → API call functions
    ├── api/api.js         → Axios instance + interceptors
    └── context/           → global problem state
```

## ✦ Deployment

### Frontend → Vercel

```bash
cd frontend && vercel --prod
# Set env: VITE_API_URL=https://your-backend.onrender.com
```

### Backend → Render

1. Push to GitHub
2. New **Web Service** → connect repo → root: `backend`
3. Build: `npm install` · Start: `node server.js`
4. Add all env vars from `.env.example` under **Environment**
